# 📅 SPBSTU A.2.17 Schedule Monitor

Сервис мониторинга изменений в расписании аудитории А.2.17 СПбПУ. Автоматически отслеживает изменения и отправляет уведомления в Telegram.

## 🔧 Как это работает

Сервис запускается как Windows-служба и работает в двух режимах:

**Мгновенные проверки** (каждые 10 минут):
1. Запрашивает актуальное расписание через API СПбПУ
2. Сравнивает со снапшотом
3. Если есть изменения — сразу отправляет уведомление в Telegram, обновляет снапшот и сохраняет изменения

**Сводные проверки** (в 10:00 и 17:00):
1. Сначала выполняется мгновенная проверка
2. Затем сравнивает эталон (`current`) с новым расписанием
3. Отправляет сводку если есть изменения
4. Обновляет эталон и снапшот
5. Проверяет конфликты в расписании

**Отправка в Telegram:**
- Сначала пробует отправить напрямую (3 попытки)
- Если не вышло — пробует через резервный HTTP-прокси на VPS
- Если и это не удалось — сообщение сохраняется в очередь
- При следующей проверке очередь пытается отправиться повторно, с пометкой о задержке

## ⚙️ Конфигурация мониторинга

Рабочие параметры находятся в `schedule_config.json`:

```json
{
    "building_id": 69,
    "rooms": {
        "1948": "Room A.2.17(Stationary)",
        "1949": "Room А.2.17(Mobile)"
    },
    "semester": {
        "start_date": "2026-09-01",
        "end_date": "2027-01-31"
    },
    "check_interval_seconds": 600,
    "summary_times": ["10:00", "17:00"]
}
```

После изменения конфигурации перезапусти Windows-службу. При запуске сервис проверяет типы значений, формат дат `YYYY-MM-DD`, формат времени `HH:MM` и корректность диапазона семестра.

## ⚙️ Установка

### 1. Клонировать репозиторий
```bash
git clone https://github.com/Kent-PR/SPBSTU-a217-schedule-monitor.git
cd SPBSTU-a217-schedule-monitor
```

### 2. Установить зависимости
```bash
pip install requests pywin32
python Scripts/pywin32_postinstall.py -install
```

### 3. Создать файл с кредами
Создай файл `tg_credentials.py` в корне проекта:
```python
TG_TOKEN = "твой_токен"
TG_CHAT_ID = "твой_chat_id"
TG_PROXY = "http://адрес_vps:порт"  # резервный прокси на случай недоступности Telegram
```

### 4. Инициализировать расписание
```python
from main import run_check
run_check(is_summary=True)
```

### 5. Установить и запустить сервис
```bash
python schedule_service.py install
sc start ScheduleMonitorService
```

## 🛠️ Управление сервисом

```bash
sc start ScheduleMonitorService    # запустить
sc stop ScheduleMonitorService     # остановить
sc query ScheduleMonitorService    # статус
python schedule_service.py remove  # удалить сервис
```

## 📦 Зависимости

- `requests` — HTTP-запросы к API и Telegram
- `pywin32` — Windows-сервис

Установка зависимостей приложения:

```bash
pip install -r requirements.txt
```

Установка зависимостей для разработки и запуск тестов:

```bash
pip install -r requirements-dev.txt
python -m pytest
```
